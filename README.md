# 三角机构：SealChat 角色卡

面向《三角机构（Triangle Agency）》跑团的 SealChat HTML 角色卡，配合 SealDice 社区插件 [triangle-agency](https://github.com/oissevalt/sealdice-plugins/blob/main/src/triangle-agency/triangle-agency.ts) 使用。

本模板已合入 SealChat（[kagangtuya-star/sealchat#293](https://github.com/kagangtuya-star/sealchat/pull/293)），包含该版本的 SealChat 会自动提供内置模板“三角机构角色卡”，无需手动导入。本仓库保存同一份模板文件 `triangle-agency-character-sheet.html`，供以下情况使用：

- 想在模板管理器中手动导入，或在此基础上修改出自己的版本；
- 想单独查看、对比模板源码。

## 配套插件

在 SealDice 中安装社区插件 triangle-agency（3.0.1）并启用，把人物卡规则设为 `ta`。九项资质（专注、共情、气场、欺瞒、主动、专业、活力、坚毅、诡秘）的根级数值就是当前 QA，另有 `<资质>上限`、`嘉奖`、`申诫`；其余内容存于 `$三角机构`。

模板内声明了插件依赖：内置模板会用 `.ta help` 自动检测插件，检测到插件缺失时才会提示。

> 本仓库早期附带的自制插件 `triangle-agency-sealchat.js`（`.taq`、`.tas`、`.tatri` 等指令）已停止维护并移除，新版角色卡不再依赖它。

## 功能概览

- **页签**：员工档案、资质保证、异常能力、人际关系、工作生活、入职问卷、规则速查。美术参照核心规则书。
- **员工档案**：大号头像框（同步 SealChat 头像）、A/R/C 色带、嘉奖 / 申诫 / 任务 MVP / 察看期记录，职能区（首要指令、许可行为、申领物）与现实区（现实触发器、过载解除）。
- **资质保证**：点击三角格设置当前 QA，可调 QA 上限，QA 为 0 时标出过载；查询混沌点数与改写失败次数；任务间隙“恢复资质到上限”。
- **检定弹窗**：发送 `.ta` / `.tr` / `.tra`，可选不计混沌、不记录改写失败，扩展规则骰在折叠区。掷骰后结算：花费 QA、三重升华的“稍后重议”与“此刻之星”都以相对 `.st` 调整发送；发送前先等待人物卡保存完成。
- **人际关系**：连结 0–9，达到 9 时加入关系网，降至 0 时失去该关系。
- **工作生活**：职能、现实、异常三条双行轨道，格子标记后显示规则书中的文件代码。
- **受限文档**：卡头左上角红三角为隐藏入口，首次点击设置密钥，之后输入正确密钥才能打开。密钥只是基本的访问门槛，私密信息仍应使用便签、线索箱。
- 群混沌与现实改写失败次数由插件记在群变量中，主持人用插件指令管理，相关指令列在“规则速查”。

## 手动导入

内置模板可直接使用。需要手动导入时：

1. 在 SealChat 中打开角色卡面板，进入“模板管理器”，点击“新增模板”。
2. 导入 `triangle-agency-character-sheet.html` 文件，规则类型会从模板中读取为 `ta`；若改为粘贴模板内容，请手动把规则类型填为 `ta`。
3. 保存后，为人物卡选择该模板，规则类型选择 `ta`（别名 `triangle-agency`、`三角机构`）。

内容与内置模板完全一致时，SealChat 会视同内置模板自动检测插件；修改过的模板属于第三方模板，插件检测不会自动执行，需要在提示中点击“检测插件”。

## 指令速查

| 指令 | 作用 |
| --- | --- |
| `.ta 专注` | 资质检定（6d4）；`--c` 不计入混沌 |
| `.tr 专注` | 现实改写请求；`--f` 失败时不记录 |
| `.tra 专注` | 扩展：D20 特殊技能检定，需支付 1 点 QA |
| `.tcs` / `.tfs` | 查询群混沌 / 本地点现实改写失败次数 |
| `.tcs 3` / `.tcs -3` | 主持人：消除 / 增加混沌 |
| `.tfs -1` | 主持人：增加 1 次现实改写失败 |
| `.tcst 0` / `.tfst 0` | 主持人：直接设置混沌 / 现实改写失败次数 |
| `.st 专注-1` | 调整资质 QA；`.st 嘉奖+3` 调整嘉奖 |

## 从旧版角色卡迁移

打开使用旧版数据（`$TriangleAgency`）的人物卡时，模板会自动迁移：旧资质名（缜密、坚持、气质、低调）与“处分”映射到新键名，只补写卡上尚不存在的属性，插件或 `.st` 已维护的新数值保持不变。代号与机构信誉等级保存到备注。旧版的燃尽计数、混沌与改写失败镜像不再使用。
