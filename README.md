# 三角机构：SealChat 角色卡 × SealDice 规则扩展

这是一套面向《三角机构（Triangle Agency）》跑团的 SealChat 角色卡，附有 Sealdice 中的 JS 掷骰指令扩展文件：

- SealChat HTML 角色卡负责人物资料、QA 与规则资源的可视化记录，并把常用指令封装成按钮。
- SealDice 扩展负责 6D4 检定、QA 后结算、过载、混沌、现实改写失败和三重升华。
- 玩家可以在看到骰点后再决定是否花费 QA，同时尽量不手动输入 SealDice 指令。

## 功能概览

### SealChat 角色卡

角色卡覆盖以下常用记录内容：

- 员工介绍与 A/R/C 三重身份。
- 九项综合素质、QA 当前值和 QA 上限。
- 嘉奖、处分、燃尽、额外过载等人物资源。
- 现实触发器、最高准则、授权行为、燃尽释放和补给。
- 职位、现实、异常三条完整双行轨道。
- 3 项异常能力、6 项职级福利、6 组现实关系。
- 12 项入职问卷，其中第 10–12 项可自定义问题。
- 密钥验证后的受限文档界面。

角色卡内置的规则按钮包括：

- 普通检定与现实改写检定。
- 查看骰点后的 QA 结算。
- 放弃尚未结算的检定。
- 同步并查看规则资源。
- 任务间隙恢复全部 QA。
- 三重升华的全员协力、补充 QA、此刻之星三类选择。

### SealDice 扩展

扩展提供：

- 三角机构规则模板与九项素质别名。
- 6D4 核心检定。
- “先掷骰、后决定 QA”的两阶段结算。
- QA 耗尽、额外过载和现实改写失败造成的过载。
- 群混沌池、地点现实改写失败的记录与人物卡镜像。
- 三重升华及其三类效果处理。
- QA 任务间隙恢复。
- 代骰目标支持与跨群、切换人物卡保护。

## 安装前提

安装前请确认：

1. SealChat 已经能够连接目标 SealDice Bot。
2. 当前频道可以读取、保存和绑定 SealDice 人物卡。
3. SealChat 中能够打开“角色卡”和“模板管理器”。

建议先安装 SealDice 扩展，再安装和绑定 SealChat 角色卡。

## 安装 SealDice 扩展

1. 打开 SealDice WebUI。
2. 进入 JS 扩展管理界面。
3. 新建或导入扩展，将 `triangle-agency-sealchat.js` 的完整内容载入。
4. 启用扩展并重新加载 JavaScript 扩展；必要时重启 SealDice。
5. 在测试群中发送 `.tas`。能够收到消息即表示指令已经注册。

## 安装 SealChat 角色卡

1. 在 SealChat 中打开角色卡面板。
2. 进入“模板管理器”，点击“新增模板”。
3. 建议填写：
   - 模板名称：`三角机构角色卡`
   - 规则类型：`ta`
   - 模板内容：粘贴 `triangle-agency-character-sheet.html` 的完整内容
   - 默认角色徽章模板：`职级{职级} 嘉奖{嘉奖} 处分{处分} 燃尽{燃尽}`
4. 保存模板。可按需要将其设为 `ta` 规则的默认模板。
5. 新建或选择一张 SealDice 人物卡，规则类型选择 `ta`，并应用刚创建的模板。
6. 将人物卡绑定到当前频道正在使用的聊天身份。
7. 打开角色卡，至少修改或保存一次字段，使九项 QA 上限等根级属性写入 SealDice 人物卡。

## SealDice 指令表

角色卡已经封装了高频指令；下表主要用于主持人管理、排错或无法使用角色卡 UI 时手动操作。

| 指令 | 功能 |
| --- | --- |
| `.ta <素质>` | 投掷普通 6D4 检定并建立待结算结果 |
| `.tr <素质>` | 投掷现实改写检定并建立待结算结果 |
| `.taq <整数>` | 花费 QA 并结算最近一次 `.ta/.tr` |
| `.tacancel` | 放弃当前人物卡最近一次待结算结果 |
| `.tas` | 查看九项 QA、上限、额外过载、群混沌、地点失败和待结算状态，并同步群资源镜像 |
| `.tarest` | 将九项 QA 当前值恢复到人物卡记录的上限 |
| `.tcs` | 查询当前群混沌池 |
| `.tcs N` | 消除 `N` 点混沌；负数表示增加混沌 |
| `.tcst N` | 直接将群混沌池设置为 `N` |
| `.tcs sync` | 将群混沌镜像到当前人物卡 |
| `.tfs` | 查询当前地点现实改写失败次数 |
| `.tfs N` | 消除 `N` 次失败；负数表示增加失败次数 |
| `.tfst N` | 直接设置地点现实改写失败次数 |
| `.tfs sync` | 将地点失败次数镜像到当前人物卡 |
| `.tatri` | 查看当前待选择的三重升华 |
| `.tatri all` | 选择“全员协力” |
| `.tatri qa <素质> <1-3>` | 将三重升华点数补充到指定素质 QA |
| `.tatri commend` | 选择“此刻之星”，嘉奖增加 3 |

### 快速结算与控制参数

- `.ta <素质> --qa=N`：投掷并立即按 `N` 结算，适用于愿意在看骰前决定 QA 的快速操作。
- `.tr <素质> --qa=N`：现实改写的快速结算形式。
- `--c`：本次结算不增加混沌。
- `--f`：现实改写失败时不记录本次失败。

这些控制参数主要用于主持人裁定、测试或特殊场景。普通玩家建议使用角色卡的两阶段按钮。
